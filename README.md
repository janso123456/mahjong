# 社内麻雀卓

それぞれのiPhoneで同じ卓に座って打てる、4人打ちのリーチ麻雀です。役・符・点数は自動で計算します。
遊ぶ人はログインもアカウントもいりません。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面と通信（親機・子機） |
| `engine.js` | 麻雀のルール（鳴き・和了判定・役・符・点数・CPU） |
| `style.css` | 見た目 |

## GitHub Pagesで公開する手順

1. https://github.com でアカウントを作ります（無料）。
2. 右上の「＋」→「New repository」を選びます。
   - Repository name：`mahjong`（好きな名前でかまいません）
   - **Public** を選びます（無料プランでPagesを使うには公開リポジトリが必要です）
   - 「Create repository」を押します。
3. 作成直後の画面で「uploading an existing file」をクリックし、
   `index.html`・`engine.js`・`style.css` の3つをドラッグして入れ、「Commit changes」を押します。
4. リポジトリの「Settings」→ 左のメニューの「Pages」を開きます。
   - Source：**Deploy from a branch**
   - Branch：**main**、フォルダ：**/ (root)** を選んで「Save」
5. 1〜2分待つと、Pagesの画面の上に公開URLが出ます。
   `https://＜あなたのユーザー名＞.github.io/mahjong/` のような形です。

あとでファイルを直したときは、同じ手順3で上書きアップロードすれば数分で反映されます。

## 遊び方

1. 全員がiPhoneのSafariで公開URLを開き、名前を入れます。
   共有ボタン →「ホーム画面に追加」しておくと、アプリのように開けます。
2. 1人が「部屋を作る」を押します。この人のiPhoneが**親機**になり、4桁の部屋番号が出ます。
3. ほかの3人は部屋番号を入れて「参加する」を押します（親機の画面の「参加用リンクをコピー」で送ったリンクから開けば、番号は入力済みになります）。
4. 人数が足りない席は、親機が「CPUを入れる」で埋められます。親機が「対局開始」を押して始めます。

### 親機の人へ

- 対局中は**このページを開いたまま**にしてください。ほかのアプリに切り替えたり画面を消したりすると、全員の対局が止まります。
- 止まってしまっても、ページを開き直して「前の部屋を再開する」を押せば続きから再開できます（同じ部屋番号で開き直すまで数秒〜十数秒かかることがあります）。

### つながらないとき

- 子機の画面に「親機とつながっていません」と出たら、親機がページを開いているか確認してください。自動でつなぎ直します。
- 会社のWi-Fiでつながらない場合は、Wi-Fiを切ってモバイル回線で試してください。
- 接続の仲介には、PeerJSの無料公開サーバーを使っています。まれにサーバーが混んでいてつながりにくいことがあります。

## ルール

25000点持ち30000点返し、ウマ10-20。喰いタンあり、後付けあり、ダブロンあり（供託・本場は上家取り）。
赤ドラ（各1枚）・東風戦／半荘戦は部屋を作った人が選べます。トビ終了あり、オーラスの親はアガリやめ・テンパイやめ。
九種九牌・四風連打などの途中流局と流し満貫はありません。ダブル役満は数えません。

## 手牌の見え方について

親機は、子機それぞれに自分の手牌だけを送ります。子機の人がほかの人の手牌を見ることはできません。
ただし親機のiPhoneは全員の手牌を持っているので、親機の人は技術的には見ることができます。
